Support

Stuck somewhere? Pick the fastest channel.

Community Q&AAsk usage questions, share setups, get answers from other operators. Bug reportsSomething broken? Open an issue with steps to reproduce. FAQ firstLogin lockouts, 404 subs, SSL fails — most answers are already here. DonateLike Zefira? Crypto wallets and contact inside.

Before you ask

  • Read the FAQ — 9 out of 10 problems end there.
  • Collect: panel version (Update section), relevant lines from journalctl -u zefira -n 100 --no-pager, and what you already tried.
  • Never post subscription tokens, passwords, backup files, or your secret.key — rotate anything that leaks.

Security issues

Found a vulnerability? Do NOT open a public issue — report it privately via GitHub Security Advisories so it can be fixed before disclosure.
