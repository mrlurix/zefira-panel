Anti-Censorship / REALITY

Generate an X25519 REALITY keypair. Put the private key into your server's Xray config; the panel embeds the public key inside every VLESS-REALITY link automatically. REALITY masquerades as normal TLS traffic to real websites — extremely resistant to DPI blocking.

Remote Access & Tunneling

Reach the panel through a normal or reverse tunnel (SSH, socat, gost, realm). Set your public URL so subscription links & QR codes stay correct behind any tunnel. Only list proxy IPs in Trusted Proxies — they are the ONLY addresses allowed to set X-Forwarded-For.

Ready-to-run tunnel scripts (uses your public URL host):

  • Normal tunnel: SSH -L forwards a local port to the panel on the server
  • Reverse tunnel: SSH -R exposes this panel from behind NAT via a VPS
  • Keep uvicorn bound to 127.0.0.1 and let the tunnel expose it

      Documentation

      1 · Quick Start

      Sign in with your admin account. On the very first run the password is printed in the server console (or preset with ZEFIRA_ADMIN_PASSWORD). Immediately:

      1. Settings → Change Admin Password — pick 10+ chars with letters AND digits.
      2. Settings → Two-Factor Auth — scan the QR with Google Authenticator/Authy and enable it.
      3. Settings → Server / Hosts Settings — set your real domain or IP; every generated config uses it.
      4. Create your first user in Users → Add User and share the subscription link.

      2 · Users

      Add User opens a dialog where you pick one or MANY protocols, volume (GB), duration (days) and an optional note. Each user gets:

      • a random 256-bit subscription token (/sub/{token})
      • independent secrets per protocol (UUIDs, passwords, WireGuard keys, OpenVPN certificates)

      Row actions: QR code · copy subscription link · download config file(s) as ZIP · pause/enable · reset token+keys (old ones die instantly) · edit · delete.

      Edit (pencil) changes note, absolute volume, exact expiry date/time (UTC) and can reset used traffic to zero.

      Status badges: Active · Not started (start-on-first-use) · Limited (volume exhausted) · Expired · Paused. Use Sort and Export CSV above the table for reporting.

      3 · Inbounds

      Inbounds are extra endpoints for configs. Define e.g. name cdn, protocol VLESS, port 2053, host cdn.example.com — every VLESS user instantly gets additional links pointing there (Marzban-style multi-inbound). Toggle OFF removes those links from all subscriptions without deleting anything. With zero inbounds defined, the global ports from Server Settings apply.

      5 · Subscriptions, QR & Formats

      • /sub/{token} — base64 v2ray-format (works in v2rayNG, NekoBox, Streisand, Hiddify...). If the user has WireGuard/OpenVPN, plain-text sections are appended.
      • /sub/{token}?format=clash — Clash / ClashMeta YAML (also auto-detected from the app's User-Agent).
      • The response includes usage headers (subscription-userinfo) so clients show remaining traffic/expiry.
      • QR button renders the current link as a scannable code, generated locally on the server.

      6 · Anti-Censorship (VLESS-REALITY)

      1. Open Anti-Censorship in the menu → press Generate New Keypair.
      2. Copy BOTH keys. The public key is embedded automatically into every REALITY link; the private key goes into your Xray server config (realitySettings.privateKey).
      3. Pick masquerade SNI sites (defaults: yahoo/samsung/microsoft). Links rotate through them and use flow=xtls-rprx-vision + Chrome fingerprint.
      4. Set the REALITY port your Xray listens on.

      REALITY borrows a real website's TLS handshake, so DPI sees ordinary traffic to a famous domain — currently the strongest no-domain-needed anti-block technology. Regenerating keys invalidates old links only after you update the server side too.

      7 · BackPack Tunnel Nodes

      Backpack (github.com/AminMGMT/BackPack) carries user traffic between an IRAN entry server and a KHAREJ exit server through 12 transports (TCP, Stealth, KCP+FEC, QUIC, WSS, ICMP spoofing...).

      1. Create Tunnel: name, transport, Iran IP, Kharej IP, tunnel port, forwarded ports (iran:kharej pairs), UDP switch. The panel generates a secure token (shown once, clipboard-copied).
      2. Download setup guide — step-by-step wizard answers for both servers including install command and the token.
      3. Run the wizard on both servers with identical values, then press Check now: the panel probes iran_ip:tunnel_port and marks the node online/offline.
      4. Token leaked? Regenerate and update both ends.

      8 · Server / Hosts Settings

      Domain or IP, per-family ports (V2Ray/Trojan/SS, Hysteria2, WireGuard, OpenVPN), tunnel DNS, OpenVPN protocol, REALITY port + SNI list, WireGuard server public key. Saved values are embedded into NEW configs immediately — old links keep their original values until you reset the token.

      9 · Remote Access & Tunneling

      • Public base URL — what subscription links and QR codes point to. Set it when the panel is reachable via a different address than the request Host (tunnels, reverse proxy).
      • Trusted proxies — ONLY these IPs/CIDRs may send X-Forwarded-For. Anything else is ignored (anti-spoofing: fake IPs cannot dodge brute-force lockouts or poison audit logs).
      • Ready scripts for SSH forward/reverse, socat, gost and realm tunnels are downloadable.

      10 · Telegram Notifications

      Create a bot with @BotFather, message it once, get chat id from @userinfobot. Save token + chat id and press Send Test. You will receive: user created/deleted, brute-force lockout alerts. The bot token is encrypted at rest and never returned by the API.

      11 · Backup & Restore

      Download Backup exports a JSON snapshot: all users (with secrets), admin(s), server/tunnel settings, templates. Store it safely — it contains everything. Restore replaces users/settings/templates and asks for your admin password to confirm. Restoring invalidates all other sessions.

      12 · User Templates

      In the Add-User dialog configure protocols/volume/duration once, press the save icon, give it a name (e.g. VIP-90d). Load it later from the dropdown; delete with the trash icon. Templates persist across backups.

      13 · Security Model

      • TOTP two-factor login (QR local, secret Fernet-encrypted)
      • scrypt password hashing, timing-safe compares, anti-enumeration dummy hash
      • JWT session in HttpOnly + SameSite=Strict cookie; password change/restore revokes everything
      • Rate limits: login 8/15min, password 6/5min, 2FA 10/10min, subscriptions 120/min, node probes 20/min
      • CSRF guard + 1 MB body cap + strict CSP (no inline scripts) + frame-deny + nosniff + noindex
      • Parameterized SQL, strict Pydantic validation, DOM built without innerHTML (XSS-safe)
      • Encrypted-at-rest secrets, 256-bit tokens, full audit log with IPs (auto-trimmed)
      • Run security_test.py any time to replay 41 attacks against your instance.

      15 · FAQ / Troubleshooting

      • Locked out? Wait 15 minutes (8 attempts limit) or restart uvicorn (limits are in-memory).
      • Links show old port? Links are frozen at creation; update Server Settings then Reset Token on affected users.
      • WireGuard handshakes fail? Forward the WG UDP port on your firewall and put the SERVER public key into Server Settings.
      • REALITY connects but no internet? Private/public key mismatch between panel and Xray config — regenerate or re-copy.
      • Behind Nginx? Terminate TLS there, proxy to 127.0.0.1:8000, add its IP to Trusted Proxies, keep --no-proxy-headers.
      • Database? Single SQLite file at instance/zefira.db (+ WAL). Back it up while the panel is stopped, or use JSON backup.
